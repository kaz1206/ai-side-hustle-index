# AI Side-Hustle Kit v1.0 🚀

このキットは、AIを活用した副業アイデアを自動収集し、高級感のあるデザインで表示する「資産型ディレクトリサイト」のスターターキットです。

## 🌟 特徴
- **運用コスト0円:** Next.jsの静的書き出し機能により、GitHub Pages等で無料で運用可能。
- **高級デザイン:** LinearやStripeを彷彿とさせる、信頼感のあるモダンなUI。
- **AI自動更新:** 付属のスクリプトを実行するだけで、Gemini AIが新しい副業ネタを自動で追加。
- **カスタマイズ自在:** 1行もコードを書かなくても、`hustles.json` を書き換えるだけで内容を更新可能。

## 🛠 セットアップ
1. `npm install` で依存関係をインストール。
2. `.env.example` を `.env` にリネームし、Gemini APIキーを入力。
3. `npm run dev` でローカル確認。
4. `npm run sync` でAIに新しいネタを考案させる。

## 💰 収益化のヒント
- **プレミアム掲載:** 自分のサービスやおすすめツールを `isPremium: true` にしてトップに掲載。
- **アフィリエイト:** 副業に役立つツールのリンクを各カードに設置。
- **キット販売:** このサイトをベースに自分流のディレクトリを作り、その構築法をコンテンツとして販売。
